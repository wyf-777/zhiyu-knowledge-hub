# 安全与隐私设计

## 1. 安全目标

- 默认确保原始文档、索引和聊天记录留在本机或企业内网。
- 防止未授权应用调用本地 API。
- 防止无权限知识进入检索上下文和模型输入。
- 最小化日志、遥测和云端模型调用中的敏感数据。
- 所有高风险能力都需要显式授权和审计。

## 2. 威胁边界

主要威胁包括：

- 恶意或被植入内容的文档
- 压缩炸弹、超大文件和解析器漏洞
- 本机其他进程访问环回 API
- 恶意网页调用未保护的 localhost 服务
- 提示词注入诱导模型泄露其他文档
- 企业多租户权限过滤缺失
- 模型输出中的恶意 HTML 或链接
- 日志和 URL 泄露 token、密码、问题或原文
- 云端模型供应商保留输入内容

## 3. 本地 API 安全

- 仅绑定 `127.0.0.1` 或平台 IPC，不绑定 `0.0.0.0`。
- 每次启动生成高熵短期令牌。
- 限制 `Origin`、Host 和 CORS，不使用通配符。
- 校验桌面壳与 API 协议版本。
- 不允许客户端传递任意文件系统路径；文件访问通过原生选择器授权句柄或内部对象 ID。
- 对上传、解析、查询和模型调用设置大小、并发和超时限制。

## 4. 文档处理安全

- 使用文件头和 MIME 双重检测，不只信任扩展名。
- 压缩文件限制展开层级、文件数量和总大小。
- 可执行文件、宏和嵌入对象不执行。
- 解析器在受限子进程中运行，设置内存和执行超时。
- 文档预览避免启用宏、脚本和外部资源。
- 对解析库和 OCR 组件建立版本与漏洞更新流程。

## 5. RAG 权限安全

- 权限过滤必须在向量召回和全文召回阶段执行。
- 不依赖大模型判断用户是否有权访问内容。
- 缓存键包含租户、用户权限版本和知识库范围。
- 引用接口再次校验文档权限，防止通过引用 ID 越权访问。
- 企业版记录知识库查询、文档查看和导出审计。

## 6. 模型与提示词安全

- 将检索内容明确标记为不可信资料，资料中的指令不得覆盖系统策略。
- 不向模型提供不必要的完整文档。
- 云端模式调用前展示数据处理提示，并允许管理员禁用云端模型。
- API Key 存放于系统密钥链：Windows Credential Manager 或 macOS Keychain。
- 不在配置文件、浏览器 localStorage、日志或 URL 中保存模型密钥。

## 7. 前端安全

- Markdown 渲染后使用 DOMPurify 等白名单净化。
- 默认禁用原始 HTML、脚本、iframe 和危险 URL 协议。
- 外部链接显示真实域名，并通过系统浏览器打开。
- 桌面 WebView 配置严格 CSP，限制脚本和网络来源。
- 不将登录凭证或问题放在 GET 查询参数中。

## 8. 数据保护

- 个人版提供知识库级备份、清除与可选加密。
- 企业版使用传输层 TLS 和服务端存储加密。
- 删除知识库时清理原文、派生文件、全文索引、向量和缓存。
- 备份文件明确说明是否加密，不以“压缩”等同于加密。
- 日志默认不记录原文；诊断包生成前进行脱敏并由用户确认。

## 9. 发布安全

- Windows 安装包进行代码签名。
- macOS 应用使用 Developer ID 签名并完成公证。
- 发布物生成 SHA-256 校验值和软件物料清单（SBOM）。
- 自动更新清单与更新包必须进行签名验证。
- 第三方模型和依赖在发布前完成许可证及供应链审查。

## 10. 安全响应

项目正式发布前需要提供：

- 安全问题报告渠道
- 支持版本与补丁策略
- 漏洞分级和响应时限
- 密钥轮换与更新撤回流程
- 企业部署的事件调查和审计导出说明
