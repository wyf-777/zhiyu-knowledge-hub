# 产品需求文档

## 1. 产品概述

Local Knowledge Hub 是一款面向个人、专业团队与企业的本地优先知识库产品。系统通过检索增强生成（RAG）将用户文档转化为可检索知识，并让用户通过自然语言获得带证据引用的回答。

## 2. 目标用户

### 2.1 个人用户

- 研究人员、学生与内容创作者
- 软件开发者和技术顾问
- 需要管理个人资料、手册、合同或笔记的用户
- 对数据隐私和离线能力有要求的用户

### 2.2 团队与企业用户

- 内部制度、产品文档和技术资料问答
- 客服、售前和交付知识辅助
- 法务、财务、人力资源等受权限约束的知识检索
- 私有化部署和审计合规场景

## 3. 关键使用场景

1. 用户创建知识库并批量导入资料。
2. 系统展示解析、OCR、切分和索引进度。
3. 用户针对一个或多个知识库提问。
4. 系统返回简洁答案及文档、页码、章节和原文引用。
5. 用户点击引用，打开原始文档并定位到相关位置。
6. 文档发生变化后，系统仅重建受影响内容的索引。
7. 企业管理员为用户或部门分配知识库权限并查看审计记录。

## 4. 功能范围

### 4.1 知识库管理

- 创建、重命名、归档和删除知识库
- 配置知识库语言、Embedding 模型、切分策略和检索参数
- 查看文档数量、块数量、索引体积和最近更新时间
- 导出与导入可迁移的知识库备份

### 4.2 文档管理

- 单文件、多文件和目录批量导入
- 支持 PDF、DOCX、XLS/XLSX、PPTX、TXT、Markdown、HTML 和常见图片格式
- 显示文件哈希、解析状态、错误原因和索引版本
- 支持重新解析、重新索引、禁用、删除和替换
- 通过哈希与版本信息识别重复或变更文档

### 4.3 文档处理

- 提取文本、标题层级、页码、表格和图片说明
- 自动识别扫描型 PDF 并进入 OCR 流程
- 保留原始文档与标准化内容之间的位置映射
- 根据标题、段落、列表、表格和语义边界进行切分
- 批量生成向量并原子写入索引

### 4.4 问答与检索

- 支持单轮和多轮问答
- 支持指定知识库、文档类型、时间范围和标签
- 同时执行全文检索、向量检索和元数据过滤
- 对候选片段进行去重、重排和上下文压缩
- 流式输出答案
- 展示引用卡片和原文片段
- 对证据不足的问题拒绝臆测

### 4.5 模型管理

- 检测和连接 Ollama、llama.cpp 或兼容远程接口
- 配置聊天模型、Embedding 模型与 Reranker
- 展示模型大小、语言、上下文长度和运行状态
- 支持按知识库固定索引模型，防止误用不同维度模型

### 4.6 企业能力

- 用户、组织、团队和角色管理
- 知识库、文档和标签级权限
- 单点登录和目录服务集成
- 操作、检索、下载与管理审计
- 集中配额和模型调用策略

## 5. 非功能需求

### 5.1 跨平台

- Windows 与 macOS 共用一套 UI、业务逻辑、RAG 流程、API 契约和数据模型，这是产品硬性验收条件。
- 不允许分别维护 Windows 产品代码和 macOS 产品代码，也不接受将 macOS 支持推迟为后续独立移植项目。
- 支持 Windows 10/11 x64。
- 支持 macOS Apple Silicon；根据发布策略支持 Intel 或 Universal Binary。
- 核心数据格式和 API 在平台间保持一致。
- 平台专属实现只能存在于文件选择、系统密钥链、通知、自动更新、签名和权限等薄适配层，并需要统一接口与跨平台测试。

### 5.2 性能目标

- 普通文本文件导入后快速进入任务队列，界面不阻塞。
- 所有耗时任务提供阶段进度和可读状态。
- 本地检索在常见个人知识库规模下达到交互级响应。
- 支持取消尚未提交索引的任务，并在异常退出后恢复可恢复任务。

具体数值需要在确定硬件基线和测试语料后通过 ADR 固化。

### 5.3 可靠性

- 索引写入使用临时版本和原子切换，避免生成半成品索引。
- 删除文档时同步清理全文索引、向量和引用映射。
- 数据库升级必须提供迁移和回滚前备份机制。

### 5.4 可解释性

- 每条引用至少包含文档、内容片段和可用的位置标识。
- 保存检索候选、分数、重排结果与最终上下文的诊断信息。
- 普通用户默认只看到简洁引用，诊断信息由高级模式控制。

## 6. MVP 验收标准

- 可以创建知识库并导入 PDF、DOCX、TXT 和 Markdown。
- 可以观察解析、切分、向量化与完成状态。
- 可以使用本地 Embedding 生成索引。
- 可以通过关键词与向量混合检索回答问题。
- 回答包含可点击的文档和页码/章节引用。
- 可以删除文档且检索结果不再出现已删除内容。
- Windows 与 macOS 至少各完成一轮安装和端到端验收。
- 同一功能提交必须同时通过 Windows 与 macOS 构建和测试，不得以平台待适配状态进入发布版本。
- 默认配置下原始文档不会离开本机。

## 7. 暂不纳入 MVP

- 自动修改用户文档
- 自主执行系统命令
- 复杂工作流编排和 Agent 工具市场
- 实时多人协同编辑
- 音视频知识抽取
- 大规模互联网爬取
- 训练或微调基础模型

## 8. 产品指标

- 文档解析成功率
- 索引任务成功率与平均耗时
- 检索命中率、MRR、Recall@K 与 nDCG
- 引用正确率和引用覆盖率
- 有依据问题的回答正确率
- 无依据问题的正确拒答率
- 首次可用时间和崩溃率
- 用户对回答“有帮助”的反馈比例
