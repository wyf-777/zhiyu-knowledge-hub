# 实施路线图

## 阶段 0：工程基线

目标：建立可持续开发的跨平台基础。

- Tauri 2、React 和 FastAPI 脚手架
- 本地 API 生命周期与短期令牌
- SQLite 迁移、日志和配置系统
- Windows/macOS 基础构建流水线
- 建立禁止平台代码分叉的 `PlatformAdapter` 边界
- OpenAPI 契约和 TypeScript 类型生成

完成标准：同一份源码能够在两个平台安装并打开应用，前端能够安全调用本地健康检查接口；任何核心模块均不存在 Windows/macOS 两套实现。

## 阶段 1：文档知识库 MVP

目标：完成从导入文档到引用回答的最小闭环。

- [x] 知识库和文档管理
- [x] PDF、DOCX、XLS/XLSX、TXT、Markdown 解析
- [ ] 后台任务、进度、取消和重试（进度与重试已完成，取消待接入）
- [x] 本地 Embedding 适配层（Ollama BGE-M3 + hashing 回退）
- [x] SQLite FTS5 与版本化向量记录
- [x] 混合检索和基础 Reranker（FTS5 + 向量 RRF + 独立本地特征重排）
- [x] Ollama 与本机 OpenAI 兼容回答模型
- [x] 流式回答与引用卡片
- [x] 文档删除和知识库重新索引 API

完成标准：满足产品需求文档中的 MVP 验收标准。

## 阶段 2：质量与多格式

目标：提升真实文档环境中的解析和回答质量。

- [x] XLS/XLSX 工作表解析
- [x] PPTX 与 HTML 本地结构解析
- [ ] 独立图片文件 OCR 导入
- [x] RapidOCR 与扫描 PDF（纯本地 CPU 路径）
- [x] DOCX/XLS/XLSX 表格感知切分
- [x] 父子块检索与父块上下文
- [x] PDF 原文坐标定位与本地高亮预览
- [x] 检索诊断界面
- [x] 版本化文档级/片段级检索评测与 hashing/BGE-M3 消融命令
- [x] 扩充合成工程回归集与 CI 阈值门禁
- [x] 脱敏企业语料来源声明和 `--require-real-corpus` 入口
- [ ] 使用经授权、脱敏并人工标注的真实企业语料完成评测
- [ ] 接入并评测模型型 Cross-Encoder Reranker
- 知识库备份、恢复和迁移

## 阶段 3：产品化

目标：形成可面向个人用户分发的稳定版本。

- 模型下载和硬件检测
- 数据加密选项
- 自动更新、签名和 macOS 公证
- 崩溃恢复和脱敏诊断包
- 新手引导与默认策略优化
- 性能、内存和大文件专项治理

## 阶段 4：企业私有部署

目标：支持多人、权限、审计和集中运维。

- PostgreSQL、Qdrant 与对象存储
- Worker 队列和水平扩展
- OIDC/SSO、组织和角色
- 知识库与文档级权限
- 审计、配额和管理控制台
- 企业备份、监控和灾难恢复

## 阶段 5：高级能力

根据用户验证结果选择性推进：

- 多知识库路由和查询规划
- 图片、图表和多模态理解
- 文档关系图谱
- 结构化数据和数据库连接器
- 可审计的工作流自动化
- 经显式授权的本地 Agent 能力

## 优先级原则

1. 先保证引用可靠和权限正确，再增加模型复杂度。
2. 先完成可评测闭环，再优化界面动画和外围功能。
3. 先验证个人本地模式，再扩展企业分布式架构。
4. 新格式必须有代表性测试文件和失败处理。
5. 高风险自动化能力不与普通知识问答共用默认权限。
6. 任何里程碑均同时验收 Windows 与 macOS，不设置“另一个平台后续移植”的完成状态。

## 里程碑管理

每个阶段开始前应确定：

- 明确范围与非目标
- 用户故事和验收标准
- 性能及硬件测试基线
- 评测语料与目标指标
- 安全和隐私检查项
- Windows/macOS 发布验证矩阵

路线图不预设具体日期。完成时间应在团队规模、模型选择、支持格式和发布渠道确定后另行估算。
